## Ainekset

| Oliiviöljyä                        | 1 rkl        |      |      |

| Vehnäjauhoja                       | noin 2 rkl   |      |      |
| Purjoa, vaalea osa viipaloituna    | 2            |      |      |

## Valmistus

1. Kuumenna paistinpannussa ruokalusikallinen voita ja öljy. Paista sipuleita kovalla lämmöllä 15–20 minuuttia, kunnes ne karamellisoituvat ja saavat kullanruskean värin. Lisää salottisipulit ja paista vaalean kullanruskeiksi.
2. Sulata kattilassa loput voista. Lisää jauhot ja sekoita pehmeäksi suurukseksi.
3. Lisää karamellisoidut sipulit, purjo ja liemet. Mausta suolalla ja pippurilla. Hauduta, kunnes sipulit ovat pehmeitä, noin 45–60 minuuttia.
4. Leikkaa leivästä 9–12 noin 1 cm paksua viipaletta ja paahda ne kevyesti. Lisää päälle juustot ja paista, kunnes juusto ruskistuu.
5. Annostele keitto kulhoihin ja tarjoa juustoleivät päällä.
