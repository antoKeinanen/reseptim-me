## Ainekset

| Ingredient       | Amount      | Unit | Note |
| ---------------- | ----------- | ---- | ---- |
| Valkokaalia      | 1 kg        |      |      |
| Porkkanoita      | 4–5         |      |      |
| Sipuleita        | 1–2         |      |      |
| Vettä            | 2–3 dl      |      |      |
| Riisiä           | ½ dl        |      |      |
| Suolaa           | 1½ tl       |      |      |
| Jauhelihaa       | 400 g       |      |      |
| Tummaa siirappia | 2 rkl       |      |      |
| Meiramia         | 2 tl        |      |      |
| Mustapippuria    | maun mukaan |      |      |

## Valmistus

1. Suikaloi kaali, viipaloi porkkanat ja hienonna sipuli.
2. Kuumenna vesi suuressa kattilassa. Lisää kaali vähitellen ja sekoita välillä. Kun kaali alkaa pehmetä, lisää porkkanat, riisi ja suola.
3. Peitä kattila ja keitä noin 20 minuuttia.
4. Ruskista jauheliha pannulla. Lisää sipuli ja kypsennä pehmeäksi. Lisää seos pataan siirapin, meiramin ja mustapippurin kanssa.
5. Hauduta vielä noin 5 minuuttia. Tarjoa puolukkasurvoksen ja ruisleivän kanssa.
