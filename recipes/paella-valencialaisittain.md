## Ainekset

| Ingredient                             | Amount                   | Unit | Note |
| -------------------------------------- | ------------------------ | ---- | ---- |
| Vettä                                  | 1 l                      |      |      |
| Kanafondia                             | pakkauksen ohjeen mukaan |      |      |
| Rosmariinia                            | 2 tl                     |      |      |
| Valkosipulinkynsiä                     | 2                        |      |      |
| Oliiviöljyä                            | paistamiseen             |      |      |
| Kanan koipireittä tai isoja suikaleita | 400 g                    |      |      |
| Iso sipuli                             | 1                        |      |      |
| Sahramia                               | noin ½ pussia            |      |      |
| Vahvaa paprikajauhetta                 | 1 tl                     |      |      |
| Tomaattipyreetä                        | noin 70 g                |      |      |
| Puuroriisiä                            | 3 dl                     |      |      |
| Sitruunaa                              | tarjoiluun               |      |      |

## Valmistus

1. Kiehauta vesi kanafondin ja rosmariinin kanssa. Anna rosmariinin hautua liemessä.
2. Murskaa valkosipuli ja hienonna sipuli. Kuumenna öljyä kasarissa ja ruskista kana.
3. Lisää sahrami kasarin kuivempaan kohtaan paahtumaan. Lisää paprikajauhe kanan päälle ja sipuli kasariin. Sekoita sahrami kanan joukkoon.
4. Lisää tomaattipyree ja puuroriisi. Kuullota riisiä hetki.
5. Siivilöi rosmariini liemestä ja kaada liemi kasariin. Sekoita kerran ja kypsennä miedolla lämmöllä noin puoli tuntia. Anna pohjan saada hieman väriä, älä sekoittele kypsennyksen aikana.
6. Tarkista riisin kypsyys ja lisää tarvittaessa vettä. Tarjoa sitruunaviipaleiden kanssa.
