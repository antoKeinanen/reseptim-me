| Ingredient | Amount | Unit | Note |
| --- | --- | --- | --- |
| Strawberries | 400 | g | Hulled and sliced |
| Greek yogurt | 400 | g |  |
| Granola | 120 | g | Vegetarian |
| Honey | 2 | tbsp |  |
| Vanilla extract | 0.5 | tsp |  |

## Instructions

1. Mix the yogurt with the honey and vanilla.
2. Spoon half the yogurt into four glasses. Add half the strawberries and half the granola.
3. Repeat the layers with the remaining ingredients.
4. Serve immediately so the granola stays crisp.
