## Ainekset

| Ingredient                         | Amount                                                 | Unit | Note |
| ---------------------------------- | ------------------------------------------------------ | ---- | ---- |
| Vehnäjauhoja                       | 5 dl (tai 4 dl perunajauhoja gluteenittomaan versioon) |      |      |
| Leivinjauhetta                     | 2 tl                                                   |      |      |
| Suolaa                             | ½ tl                                                   |      |      |
| Sokeria                            | 4 dl                                                   |      |      |
| Kaakaojauhetta                     | 1 dl                                                   |      |      |
| Kuumaa vettä                       | 1½ dl                                                  |      |      |
| Kananmunia                         | 2                                                      |      |      |
| Voita tai margariinia, sulatettuna | 200 g                                                  |      |      |
| Vadelma- tai aprikoosihilloa       | 1 purkki, lisää tarpeen mukaan                         |      |      |
| Sokerimassaa                       | halutessasi                                            |      |      |

## Valmistus

1. Kuumenna uuni 175 °C:seen. Vuoraa uunivuoka leivinpaperilla.
2. Sekoita kuivat aineet keskenään ja siivilöi kaakaojauhe sekä leivinjauhe mukaan.
3. Sekoita sulatettu rasva, kuuma vesi ja kananmunat. Yhdistä kuivat ja kosteat aineet tasaiseksi taikinaksi.
4. Paista vuoassa 50–65 minuuttia. Anna kakun jäähtyä kokonaan.
5. Murenna kakku kulhoon. Sekoita ensin joukkoon noin puolet hillosta ja lisää tarvittaessa, kunnes massa pysyy koossa.
6. Painele massa takaisin vuokaan tuorekelmun päälle ja jäähdytä, tai muotoile siitä haluamasi muotoinen kakku. Sivele päälle hilloa ja viimeistele halutessasi sokerimassalla.
