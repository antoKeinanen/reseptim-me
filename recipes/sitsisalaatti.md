## Ainekset

| Ingredient            | Amount       | Unit | Note |
| --------------------- | ------------ | ---- | ---- |
| Valkokaalia           | 1 pieni kerä |      |      |
| Edam-juustoa          | 1 iso pala   |      |      |
| Auringonkukansiemeniä | 1 pussi      |      |      |
| Oliiviöljyä           | 3 osaa       |      |      |
| Valkoviinietikkaa     | 1 osa        |      |      |
| Suolaa ja pippuria    | maun mukaan  |      |      |

## Valmistus

1. Suikaloi kaali ja kuutioi juusto.
2. Sekoita kastikkeeksi kolme osaa oliiviöljyä ja yksi osa valkoviinietikkaa. Mausta suolalla ja pippurilla.
3. Yhdistä kaali, juusto, siemenet ja kastike. Anna maustua jääkaapissa pari tuntia ennen tarjoilua. Älä jätä salaattia tekeytymään yön yli, jotta kaali säilyy rapeana.
