## Ainekset

| Ingredient     | Amount  | Unit | Note |
| -------------- | ------- | ---- | ---- |
| Riisimaitoa    | 4 dl    |      |      |
| Sokeria        | 2 rkl   |      |      |
| Margariinia    | 50 g    |      |      |
| Riisijauhoja   | ¾–1¼ dl |      |      |
| Vaniljasokeria | ½ tl    |      |      |

## Valmistus

1. Kuumenna riisimaito, sokeri ja margariini kiehuvaksi.
2. Vatkaa joukkoon riisijauhot ja laske lämpöä. Anna kastikkeen poreilla miedolla lämmöllä noin viisi minuuttia välillä sekoittaen. Varo, ettei kastike pala pohjaan.
3. Nosta kattila liedeltä ja sekoita joukkoon vaniljasokeri.
4. Jäähdytä kastike ja vatkaa tasaiseksi. Maku ja koostumus paranevat, jos kastike saa tekeytyä jääkaapissa; vatkaa se vielä ennen tarjoilua.
