## Ainekset

| Ingredient                | Amount         | Unit | Note |
| ------------------------- | -------------- | ---- | ---- |
| Kanttarelleja             | 2 l            |      |      |
| Sipuli                    | 1              |      |      |
| Voita                     | tarpeen mukaan |      |      |
| Kermaa                    | noin 5 dl      |      |      |
| Valkopippuria             | maun mukaan    |      |      |
| Rakuunaa ja muita yrttejä | maun mukaan    |      |      |
| Suolaa                    | maun mukaan    |      |      |

## Valmistus

1. Hienonna sipuli ja kuullota se voissa. Halutessasi lisää rakuunaa jo tässä vaiheessa.
2. Lisää kanttarelleja pannulle kourallinen kerrallaan. Lisää tarvittaessa voita ja sekoittele, kunnes sienet alkavat pehmetä ja muodostaa muhennosmaisen pohjan.
3. Lisää loput sienet. Mausta valkopippurilla, rakuunalla ja halutessasi muilla yrteillä.
4. Lisää kermaa vähitellen, kunnes kastike on täyteläinen. Hauduta, kunnes kastike tarttuu lusikkaan. Mausta suolalla ja anna levätä viisi minuuttia ennen tarjoilua.

## Vinkki koostumukseen

Kastike on sopivan sakeaa, kun se tarttuu lusikkaan. Lisää kermaa vähitellen ja hauduta, kunnes koostumus on haluamasi.
