## Vohvelit

| Ingredient                           | Amount        | Unit | Note |
| ------------------------------------ | ------------- | ---- | ---- |
| Kaura-, soija- tai muuta kasvimaitoa | 3 dl          |      |      |
| Öljyä                                | ½ dl          |      |      |
| Sokeria                              | 2 rkl         |      |      |
| Suolaa                               | ½ tl          |      |      |
| Vaniljajauhetta tai vaniljasokeria   | ¼ tl tai 2 tl |      |      |
| Leivinjauhetta                       | 1 tl          |      |      |
| Vehnäjauhoja                         | 3½ dl         |      |      |

## Valmistus

1. Laita vohvelirauta kuumenemaan. Sekoita kasvimaito, öljy, sokeri, suola ja vanilja.
2. Siivilöi joukkoon leivinjauhe ja jauhot. Sekoita tasaiseksi.
3. Kaada kuumaan rautaan noin ¾ dl taikinaa kerrallaan. Paista kansi kiinni 2–3 minuuttia tai kunnes vohveli on kypsä. Avaa kansi varovasti.
4. Tarjoa vohvelit heti tai pidä ne rapeina jäähdytysritilällä.

## Kookoskermavaahto

| Ingredient    | Amount      | Unit | Note |
| ------------- | ----------- | ---- | ---- |
| Kookoskermaa  | 1 purkki    |      |      |
| Vaniljaa      | maun mukaan |      |      |
| Kookossokeria | maun mukaan |      |      |

Jäähdytä kookoskerma jääkaapissa yön yli. Lusikoi pakkauksen paksu osa kulhoon ja jätä vetisempi neste pois. Vatkaa muutama minuutti, mausta vaniljalla ja kookossokerilla. Pursotettavaa vaahtoa varten jäähdytä vielä vähintään tunti.

## Suklaaversio

Lisää perustaikinaan 2 rkl kaakaojauhetta ja 50 g pieneksi pilkottua maidotonta suklaata. Sekoita kaakao nesteisiin ennen jauhoja ja lisää suklaapalat lopuksi. Paista tavalliseen tapaan.

## Vinkkejä paistamiseen

Paista vohveli avaamatta rautaa kesken paiston, jotta se kypsyy tasaisesti eikä repeä. Heikkokuntoisen vohveliraudan pinnan voi sivellä kevyesti öljyllä. Avaa rauta kypsän vohvelin kohdalla hitaasti. Jos valmistat vohvelit etukäteen, aseta ne vierekkäin ritilälle. Päällekkäin pinottujen kuumien vohveleiden höyry pehmentää ne.
